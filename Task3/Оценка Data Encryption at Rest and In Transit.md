## Оценка Data Encryption at Rest and In Transit

| **Данные**                              | **В чём необходимость защиты**                                                        | **Инструменты защиты**                                                                                          |
|-----------------------------------------|---------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|
| **Паспортные данные**                   | Нарушение 152-ФЗ, риск идентификации личности и мошенничества                         | **Хранение:** AES-256 шифрование на уровне БД, KMS<br>**Передача:** TLS 1.3, HTTPS                              |
| **Медицинская карта**                   | Раскрытие диагноза, нарушение врачебной тайны, требования 152-ФЗ                      | **Хранение:** Шифрованные контейнеры, токенизация<br>**Передача:** TLS 1.3                                      |
| **Адрес проживания клиента**            | Потенциально идентифицирующая информация, риск целевой рекламы и вторичной корреляции | **Хранение:** Шифрование на уровне поля в БД<br>**Передача:** TLS 1.3                                           |
| **Контактные данные (телефон, e-mail)** | Риск фишинга, социальной инженерии, спама                                             | **Хранение:** Шифрование, обфускация<br>**Передача:** HTTPS                                                     |
| **История посещений врача**             | Нарушение конфиденциальности лечения и состояния здоровья                             | **Хранение:** Токенизация + ротация ключей<br>**Передача:** TLS 1.3, защищённые API                             |
| **Биометрические данные**               | Крайне чувствительные, неизменяемые; утечка = постоянная угроза                       | **Хранение:** Хэширование, HSM<br>**Передача:** TLS 1.3 + шифрование на клиенте                                 |
| **Платёжные данные**                    | Финансовые потери, нарушение PCI DSS                                                  | **Хранение:** PCI DSS-хранилище, токенизация, шифрование с KMS<br>**Передача:** TLS 1.3 + шифрование на клиенте |
| **Внутренние отчёты и аналитика**       | Коммерческая тайна, риск конкурентной разведки                                        | **Хранение:** Шифрование файлов/БД, IAM-доступ<br>**Передача:** VPN, TLS 1.3                                    |
| **Данные мониторинга/телеметрии**       | Возможность раскрытия информации о работе системы, маршрутах данных                   | **Хранение:** Обезличивание, IAM-доступ, шифрование<br>**Передача:** TLS 1.3, защищённый лог-прокси             |
